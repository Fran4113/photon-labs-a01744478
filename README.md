# Photon Labs — Landing page A01744478

Página estática del proyecto académico TE1020, Análisis de Circuitos Eléctricos. Incluye diseño adaptable, logo propio y secciones informativas sobre el futuro cotizador solar.

## Publicar en GitHub Pages

1. En GitHub, crea un repositorio público llamado `photon-labs-a01744478`.
2. Sube `index.html`, `styles.css` y la carpeta `assets` (con `logo.png`) a la raíz del repositorio. También puedes subir este README.
3. Abre **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Selecciona la rama `main` y la carpeta `/(root)`, luego **Save**.
6. Espera a que GitHub muestre el enlace de publicación. Normalmente será `https://TU-USUARIO.github.io/photon-labs-a01744478/`.

La página no requiere instalaciones, frameworks ni bases de datos. El cotizador funcional es una etapa futura del proyecto.
